## About Me

I'm Sina Rezaei, a project manager, digital strategist, creator, and full-stack developer interested in how technology, strategy, and execution work together.

I approach projects as interconnected systems rather than isolated tasks. My work spans software development, digital products, analytics, content creation, and project coordination. I enjoy exploring a problem from different angles, identifying the underlying structure, and turning ideas into practical solutions.

I work across different technologies and adapt the stack to the problem instead of forcing every project into the same framework. For me, code is one part of the process: understanding the problem, designing the solution, validating the result, and improving the system matter just as much.

**Current focus:** Building web experiences, exploring system design, developing technical projects, and publishing practical ideas about software and AI.
